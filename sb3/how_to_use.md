# 如何使用此文件夹下的文件？

以Android手机为例（图中所示应用有MT管理器和Chromium，文件为此仓库下的 /newyearcelebration.html ，其他设备或同类应用同理）

1. 下载你要下载的那个作品的文件夹下的所有文件，打开文件所在目录 ![下载所有文件](https://cloudflareimg.cdn.sn/i/6ae6d2f2bb7d0_1793512178.webp)
2. 全选这些文件，长按，选择“压缩” ![全选，长按，压缩](https://cloudflareimg.cdn.sn/i/6ae6d34e8d02b_1793512270.webp)
3. 给文件起个你记得住的名字 ![给新文件命名](https://cloudflareimg.cdn.sn/i/6ae6d36c8dcad_1793512300.webp)
4. 恭喜你处理好了所有文件 ![处理所有文件（并移动到其他记得住的目录）](https://cloudflareimg.cdn.sn/i/6ae6d381ebc96_1793512321.webp)
5. 打开[TurboWarp](https://turbowarp.org)加载文件看看吧！（原版Scratch可能会加载失败，其他软件我不确定能否打开）
