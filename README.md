# TiryWebsite

Tiry 的官网。

![TiryHi 图标](https://cloudflareimg.cdn.sn/i/6ae6e11d21c3f_1793515805.png)

> 这是一个由一群初中生发起的项目。本仓库包含了团队官网以及 TiryHi WebApp 的完整前端代码。TiryHi Android App 暂未发布到 GitHub，之后我们会考虑发布。

## 📖 关于官网

这个网站不仅是 Tiry 团队对外的名片，也是我们技术沉淀的展示区。通过官网，你可以了解我们的团队成员、查看我们的开源项目、体验互动小工具，甚至可以在这里直接申请投稿。

我们采用了 **Material 3 Expressive** 设计规范，全站支持浅色/深色模式自动跟随系统。

## ✨ TiryHi 功能一览

TiryHi 是一款面向 Tiry 团队（及所有人）的工具箱应用，包含：

| 功能 | 说明 |
|---|---|
| **倒计日** | 记录生日、纪念日，实时显示周年数与剩余天数 |
| **计数器** | 多个独立计数器，支持加减、重置、自定义步长 |
| **浏览器** | 收藏常用网页，一键新标签打开或内嵌 Iframe 显示 |
| **Intent** | 保存 Android Intent 快捷指令，一键启动手机应用 |
| **福利群** | 打卡记录与获奖进度计算 |
| **设置** | 主题、启动页、记住我、浏览器默认行为等 |

## 🚀 快速访问

直接访问新官网：[**https://tiry.itlaozai.top/**](https://tiry.itlaozai.top/)

如果你希望体验 TiryHi WebApp：
1. 首次进入会显示欢迎页，点击「开始吧」。
2. 输入暗号 → 解锁全部功能。
3. 或者选择直接登录 → 仅限制浏览器和 Intent 功能。

### ⚠️ 你有必要注意

- **暗号** 可以在 QQ 群（见上）@Q群管家 发送 **scrept** 获取。
- 目前前端主要针对手机端竖屏进行优化，暂无横屏、大屏（如 PC 端）的深度适配。
- 部分网页的图标（Favicon）还未添加完毕，因为我们只能用手机处理代码，暂时无法处理部分大文件，之后会逐步完善。

## 🛠️ 技术栈

- **纯静态多页 Web**（无需繁琐的构建，拉取即可运行）
- **纯原生 HTML/CSS/JS**，零外部框架依赖
- ~~家里没电脑，也没服务器，更没有机房 :)~~
- **Material 3 Expressive** 设计系统
- **IndexedDB** 本地数据持久化
- 支持浅色 / 深色模式自动跟随系统

## 🔒 隐私说明

所有数据（计数器、纪念日、Intent 等）均保存在 **用户浏览器的本地存储（IndexedDB）** 中，**不会上传到任何服务器**。清除浏览器数据会同时清除这些内容。
