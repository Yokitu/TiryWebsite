# TiryHi WebApp

一款为你而生的工具箱应用。

![TiryHi 图标](https://cloudflareimg.cdn.sn/i/6ae6e11d21c3f_1793515805.png)

> 本项目基于 TiryHi Android App v1.4 Beta 2 开发，是其 Web 版本。Android App 暂未发布到 GitHub，之后我们会考虑发布。

## 简介

TiryHi 是一个（不止）面向 Tiry 团队的工具箱应用，包含倒计日、计数器、浏览器书签、Intent 快捷指令、福利群打卡等多种实用功能。采用 Material 3 Expressive 设计，支持浅色/深色模式自动切换，数据本地持久化保存。

## 功能

| 功能 | 说明 |
|---|---|
| **倒计日** | 记录生日、纪念日，实时显示周年数与剩余天数 |
| **计数器** | 多个独立计数器，支持加减、重置、自定义步长 |
| **浏览器** | 收藏常用网页，一键新标签打开或内嵌 Iframe 显示 |
| **Intent** | 保存 Android Intent 快捷指令，一键启动手机应用 |
| **福利群** | 打卡记录与获奖进度计算 |
| **设置** | 主题、启动页、记住我、浏览器默认行为等 |

## 使用方式

直接访问：[https://tiry.itlaozai.top/](https://tiry.itlaozai.top/)

首次进入会显示欢迎页，点击「开始吧」后：
- 输入暗号 → 解锁全部功能
- 直接登录 → 限制浏览器和 Intent 功能

### 你有必要注意

- 分享链接时请分享 **完整链接（含 https://）**（有人反馈跳转的页面不符合预期，亲测发现该用户未复制完整链接）。
- **暗号** 可以在QQ群（见上）@Q群管家 发 **scrept** 获取。
- 目前没有对 横屏、大屏 做适配。
- 部分网页图标未添加（手机端不能快速访问大文件，所以之前上传的部分大文件未添加图标，之后会改）。

## 技术栈

- 纯静态多页 Web
- 纯原生 HTML/CSS/JS，零外部框架依赖
- ~~家里没电脑，也没服务器，更没有机房 :)~~
- Material 3 Expressive 设计系统
- IndexedDB 本地数据持久化
- 支持浅色 / 深色模式自动跟随系统

## 隐私说明

所有数据（计数器、纪念日、Intent、书签等）均保存在 **用户浏览器的本地存储（IndexedDB）** 中，**不会上传到任何服务器**。清除浏览器数据会同时清除这些内容。
